Scientific Knowledge Extraction

Ongoing · MIT CSAIL, Jacob Andreas Lab

The question

When a language model solves a domain problem correctly, it is relying on some implicit procedure — a method it has picked up but never states. Checking whether the final answer is right tells you nothing about that procedure. This project asks whether we can recover it: surface the latent structure behind a model's reasoning, rather than just grading its output.

Approach

The work extends the self-consistency framework from Self-CTRL to elicit and pin down the procedures a model uses on scientific problem-solving tasks, with the aim of expressing that model-discovered structure as explicit, auditable claims a researcher can inspect, test, and build on.

This is active, in-progress research; results and a full write-up are forthcoming.
